# DOE User Facilities Company Project Graphics

Static GitHub Pages site for DOE-SC user facility company-project graphics.

- `index.html` shows the compiled PDF in an embedded frame and the individual interactive panels below it.
- `exports/doe-user-facilities-company-project-graphics.pdf` is the compiled PDF.
- `exports/panels/` contains high-resolution PNG exports of each panel.
- `projects.html` is the industry-project index.

GitHub Pages is deployed by `.github/workflows/pages.yml` from the `main` branch.
